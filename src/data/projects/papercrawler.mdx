# Paper Crawler

A spider that reads ML papers for you.

A spider crawls down an arXiv ML paper, marking up the words it walks over - metrics glow, numbers blow up, datasets get boxed - while **Gemini** explains each section in plain English. When the model hands back the one phrase that matters (`KEY: 28.4 BLEU`), the spider runs to that phrase and puts a box around it.

No dependencies, no build step. Python standard library and ES modules only.

## What it does

**PAPER CRAWLER** turns dense ML papers into a guided walk. Instead of parsing walls of prose, you get a spider that crawls top-to-bottom, highlighting metrics, numbers, and datasets as it goes. Gemini explains each section in plain English at your chosen level - beginner, student, or researcher.

Pick up where you left off: paper, reading level, scroll position, and section are saved to `localStorage`, and shareable via URL (`?paper=1706.03762&level=researcher`).

## Key features

### The spider

- **IK legs + tetrapod gait**: canvas spider with inverse-kinematics legs that walks the paper from top to bottom
- **Markup brain**: metrics glow, numbers blow up, datasets boxed, key phrases highlighted - painted with `::before` bars so the page never reflows
- **Steerable**: click anywhere to send it there, or re-drop with `D`

### Paper library

- **Your papers**: everything in `papers/`, searchable by title, id, or author
- **Add a paper**: type an arXiv id or URL - the server downloads it and streams progress back
- **Table of contents**: click a section and the spider sprints there

### AI explainer

- **Plain English**: Gemini explains each section in under 70 words, with a `KEY:` line naming the one phrase that matters
- **Three levels**: beginner (CS freshman), student (basic ML), researcher (precise and technical)
- **Explain a selection**: select any passage and press `E`
- **Export**: download a Markdown breakdown or Crawler Notes as JSON

### Safe by default

- **API key stays on the server** - `GEMINI_API_KEY` is read from `.env`, never reaches the browser
- **Static allowlist**: only `index.html`, `css/`, `js/`, and `papers/` are served
- **Content-Security-Policy**: downloaded papers can show figures but cannot run scripts

## Tech stack

**Backend:** Python standard library only - no pip, no virtualenv, no build step. `serve.py` handles static hosting, SSE streaming, and proxies Gemini so your API key never leaves the server.

**Frontend:** Vanilla JS ES modules - no framework, no bundler. Canvas rendering for the spider, strict frame loop (read → update → draw → commit) so the DOM never reflows under the spider's feet.

## How it works

1. **Open the library drawer** (`L`) - type an arXiv id (`1706.03762`) or URL and press Enter
2. **The spider drops** onto the paper and walks down it, section by section
3. **Gemini explains** each section in plain English at your chosen reading level
4. **The spider boxes** the one key phrase (`KEY: 28.4 BLEU`) the model identifies
5. **Pick up where you left off** - state saved in `localStorage`, shareable via URL

## Quick start

```bash
# Clone
git clone https://github.com/aridepai17/PAPER-CRAWLER.git
cd PAPER-CRAWLER

# Add your Gemini API key (free from aistudio.google.com)
echo "GEMINI_API_KEY=your-key-here" > .env

# Run
python3 serve.py
# Open http://localhost:5173 - type an arXiv id (e.g. 1706.03762) and press Enter
```

No `npm install`, no `pip install`, no build step.
